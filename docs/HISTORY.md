# 开发记录

按版本倒序之外的原始归档见文末。这里保留每一步交互与动效的调整原因，方便回头查「为什么当时这么改」。

## 版本管理约定

- 每版一个文件夹：`vNNN_日期-时间_一句话说明`
- 文件夹里同时放 `桌面清单.exe`（正式）和 `桌面清单-调试.exe`（远控调试用，实心不透明底）
- 只保留最近 5 版，多的先删最旧的
- 根目录的两个 exe 永远是最新版，覆盖它们不影响归档
