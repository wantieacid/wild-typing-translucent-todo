# 使用说明

## 基本操作

- 在底部输入行打字，按回车加一条。中文输入法的候选框会跟着光标走。
- 点一下左边的方框打勾，打勾的字会划线、褪成灰色。只有方框能打勾，别的区域点了不会勾。
- 长按方框填满，是打勾；长按右边的 ✕，是删除。长按期间会有抖动和冲击波。
- 长按一行中间的空白或文字，拖动它换顺序。拖着的那行会浮起来，原位置有一条亮线告诉你插到哪儿。
- 排在第一位的字最大、有颜色，其余的都是小号灰字，只当好认的备注。
- 拖窗口边缘可以改大小，拖标题区域可以挪位置，位置和大小会自动记住。
- 右上角的 ✕ 是退出。滚轮滚动列表；`Esc` 清空输入，拖动中按 `Esc` 取消拖动。

## 开机自启动

程序会写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的启动项。要关掉就去 任务管理器 → 启动应用，找到「桌面清单」右键禁用。程序只在启动项已存在时修正路径，不会自己加回来；程序被挪到别的文件夹后，启动项里的路径会在下次运行时自动改对。

## 数据存在哪里

- 清单和窗口位置：`%APPDATA%\桌面清单\todo.json`
- 崩溃日志：`%APPDATA%\桌面清单\crash.log`
- 这个 JSON 可以自己备份、拷到别的机器接着用。删了它就是空清单。

## 两个版本挑一个

- `桌面清单.exe`（自包含，约 63 MB）——不用装任何东西，直接双击。发给别人用这个。
- `桌面清单-轻量版.exe`（约 0.2 MB）——体积小，但机器上得先装 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)（选「.NET Desktop Runtime 8.0」的 x64 安装包）。没装的话双击会弹窗提示去下载，装过一次就永久能用。
- 两个是同一个程序，数据、位置、行为全一样，别同时开两个。

## 注意

- 它被设置成对截图和录屏不可见（`WDA_EXCLUDEFROMCAPTURE`），属于功能特性，不是坏了。需要录制界面时请用调试版（`TDL_DEBUGUI` 编译，不启用抓屏排除）。
- 同一台机器只能开一个，重复双击会提示已经在运行。
- 只需要 Windows 10 1809 或更新的 64 位系统；Windows 11 都行。自包含版只打了 x64，ARM 的 Windows 要另外编译。
